# Moxa UPort 11x0 historical Linux driver

**9base status: Preserved.** Reference fork of the vendor [Moxa-Linux/mxu11x0](https://github.com/Moxa-Linux/mxu11x0) sources for the UPort 11x0 USB-to-serial family. Documentation reconstructed from repository history on 8 October 2026.

The retained default branch is `buster-4.19.0-amd64/master`, representing the Debian Buster/kernel 4.19 vendor branch. Before documentation curation it exactly matched the same-named upstream branch; no 9base-specific branch development was established. The driver and vendor documentation remain Moxa and the upstream contributors' work. This copy is no longer maintained by 9base.

The original vendor [readme.txt](readme.txt), headed with Moxa's 2019 copyright and dated 19 August 2020, remains unchanged. It contains device coverage, build/install instructions, device naming and troubleshooting. See also [version.txt](version.txt) and the retained [driver sources](driver).

This archive documents a historical vendor source snapshot. It does not promise compatibility with current kernels or distributions, and the driver was not built or loaded as part of documentation curation. All existing source notices, license references and branch history are preserved.
